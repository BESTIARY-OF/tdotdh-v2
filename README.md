# TDOTDH v2 monorepo workline

This is the separate development line for the next field-guide generation. It does not replace or modify the v1 staging worktree.

The first slice establishes packed occupancy, deterministic weighted work tickets, a versioned field-metrics contract, and package boundaries for workers, persistence, interchange, and browser handoff.

Download the source scaffold from `tdotdh-v2-monorepo-8be3840.zip`. The workline currently passes its packed-occupancy smoke test and syntax checks.

The stable v1 handoff is [BESTIARY-OF/tdotdh-field-guide](https://github.com/BESTIARY-OF/tdotdh-field-guide) with data in [MAPS-OF/SEDLEC-00Q](https://github.com/MAPS-OF/SEDLEC-00Q).
